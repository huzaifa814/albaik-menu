Set up

Once per device

Making the GitHub token
  1. github.com → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → albaik-menu
  3. Permissions → Repository → Contents: Read and write. Nothing else.
  4. Expiry: 1 year. Diary a reminder to replace it.
Scoped that way the token can only edit this one menu repo. It cannot touch any other repo or the GitHub account. If it ever leaks, revoke it on that same page and set up again.
